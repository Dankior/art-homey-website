ART HOMEY — исправленная версия, 28.09.2026

Начните с README-RU.md. Там есть локальный запуск и пошаговая инструкция
для бесплатного тарифа Cloudflare Workers + D1 и уведомлений в Telegram.

Локальный запуск (Node.js 24 LTS и pnpm 11):
  pnpm install --frozen-lockfile
  pnpm db:local
  pnpm preview:local
Откройте http://127.0.0.1:8787

Файлы страниц: docs/
Сервер заявок: server/requests.mjs
Уведомления Telegram: server/notifications.mjs
Конфигурация локального запуска: wrangler.standalone.jsonc
Проверки: pnpm test, pnpm typecheck, pnpm lint, pnpm build, pnpm check:deploy

Это исходный проект, не опубликованный сайт.
Для публикации понадобятся ваш бесплатный аккаунт Cloudflare и Telegram-бот.
Никаких токенов и реальных данных клиентов в архиве нет.
Простой просмотр docs/index.html не запускает сервер заявок.
