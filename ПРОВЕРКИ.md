# ART HOMEY — результат исправлений

Дата: 28 сентября 2026 года.

Изменения внесены в указанную папку ART HOMEY/Сайт/art-homey-2026. Структура docs, история Git и существующие фотографии сохранены. Коммиты, отправка на GitHub и публикация не выполнялись.

## Исправлено

- Ввод и серверная проверка российского телефона, нормализация для хранения.
- Подтверждение отправки и кнопка «Новая заявка»; повторный квиз начинается с первого шага.
- Кнопка «Далее» позволяет сохранить выбранный ответ после возврата назад.
- При сбое сети введённые данные остаются; повторная отправка в той же форме использует тот же идентификатор и не создаёт дубль в БД.
- Сохранение в D1 и подготовленная интеграция Telegram с повторными попытками по расписанию.
- Базовые ограничения частоты, объёма запроса, проверка согласия и поля-ловушки.
- Фокус мобильного меню, подписи точек слайдеров, учёт reduced motion.
- Метаданные восьми страниц; удалены пустые фотоблоки и стоковые иллюстрации команды/этапов.
- Восстановлена сборка; добавлена самостоятельная конфигурация Worker для недорогого запуска.

## Проверено

- 29 автоматических тестов — проходят (включая DOM-сценарии форм, телефон, реальные SQL-запросы в SQLite, дубли, ошибки БД и уведомлений).
- TypeScript — без ошибок.
- Сборка Vinext — успешно.
- Сборка Worker без публикации — успешно, обработчик около 12,7 КиБ до сжатия.
- ESLint — 0 ошибок, 2 предупреждения о неиспользуемых функциях из исходного app.js.
- Локальный Worker: восемь HTML-страниц и модуль проверки данных отвечают 200; заявка сохраняется с 201; повтор возвращает 200 и тот же ID; неполный телефон получает 400.
- Схема Drizzle согласована с миграциями. Миграции применялись к локальной базе.
- Изменения прошли отдельную проверку кода; найденная ошибка возврата в квизе исправлена и покрыта регрессионным тестом.

## Что остаётся перед запуском

- Реальный браузерный просмотр на телефоне и компьютере: автоматизация браузера в этой сессии завершается ошибкой среды, поэтому визуальная вёрстка и реальные Safari/Chrome не подтверждены. DOM-тесты не заменяют эту проверку.
- Создать/подключить ваш бесплатный аккаунт Cloudflare и базу D1; указать фактический адрес сайта командой configure:hosting.
- Создать Telegram-бота и добавить токен и ID рабочего чата в секреты Worker. Настоящая доставка не проверялась: действующие токены не предоставлены.
- Согласовать текст политики обработки данных с фактическими сервисами и реквизитами владельца. Исходный текст политики не проходил юридическую переработку.

GitHub Pages показывает страницы из docs, но не исполняет API заявок. Для форм инструкция предлагает размещать сайт целиком на Cloudflare Workers Free + D1; тарифы и бесплатные лимиты со ссылками приведены в README-RU.md. Платные сервисы не подключены.

Рабочая папка, отсутствовавшая по прежнему пути, найдена в Корзине и восстановлена копированием; исходник в Корзине не удалялся. Перед переносом изменений сохранена отдельная резервная копия текущего проекта в рабочем каталоге задачи.

ZIP содержит исходники, фотографии, тесты, конфигурации с пустыми секретами и инструкцию. История Git, зависимости, кэши и локальная тестовая база исключены.
