ART HOMEY — актуальная версия от 27.09.2026 (очищена и структурирована)

Страницы сайта: public/*.html
Фотографии: public/images/
Стили: public/style.css + public/improvements.css (+ catalog.css / materials-extra.css где нужно)
Скрипты:
  - public/app.js          — основной (меню, слайдеры, анимации, фильтры)
  - public/leads.js        — формы заявок
  - public/contact-widget.js
  - public/photo-viewer.js — увеличение фото (index, projects)

API заявок: app/api/requests/route.ts + Cloudflare D1 (db/)

Для разработки:
  Node.js >= 22.13, pnpm
  pnpm install
  pnpm dev

Статический просмотр: просто откройте public/index.html или поднимите любой static-server в папке public/.

Исправления в этой версии:
  - убрана вложенная копия art-homey-website
  - удалены __MACOSX / .DS_Store
  - добавлены null-checks в слайдерах (showcase, testimonials, project sliders)
  - унифицированы подключения скриптов во всех HTML
  - код app.js снабжён структурой и комментариями
