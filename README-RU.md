# ART HOMEY — запуск исправленной версии

Проект подготовлен для бесплатного старта на Cloudflare Workers + D1. Уведомления поступают через Telegram Bot API. Аккаунты, база и бот должны принадлежать владельцу сайта. В архиве нет активных ключей, подключённого рабочего чата и опубликованного адреса.

## Что изменено

- Номер можно вводить как `9060561819`, `89060561819`, `+79060561819`. Полный номер форматируется при уходе из поля; редактирование и удаление цифр не перехватываются маской. В БД сохраняется `+79060561819`.
- После отправки появляется отдельное подтверждение и кнопка «Новая заявка». Повторный квиз начинается с первого шага; кнопка «Далее» позволяет продолжить с тем же ответом после возврата назад.
- Ошибки сети сохраняют введённые данные. Повтор с тем же содержимым в текущей форме использует тот же идентификатор и не создаёт дубль.
- Сервер проверяет телефон, категорию, бюджет, согласие, размер запроса. Не более трёх новых заявок с одного телефона за час. Это базовая защита, не полноценная антибот-система.
- Заявка сначала сохраняется в D1. Уведомление Telegram отправляется отдельно; при сбое повторяется по расписанию, до пяти готовых уведомлений за проход. Задержка повторов растёт до часа. Платная рассылка Telegram отключена.
- Меню переводит фокус внутрь, удерживает его и возвращает на кнопку. Точки слайдеров подписаны; автоматическое движение учитывает reduced motion.
- Удалены пустые фотоблоки производства и стоковые иллюстрации команды/этапов; тексты и основной дизайн сохранены.
- Страницы получили согласованные canonical и Open Graph. Основной адрес главной — `/index.html`, корень перенаправляется туда.
- Восстановлена конфигурация исходной сборки Vinext. Добавлен небольшой самостоятельный Worker для размещения имеющихся HTML-страниц и API без серверного React-рендеринга.

Папка `docs` сохранена из вашей актуальной структуры GitHub Pages. Сам GitHub Pages не выполняет серверный API: для работы форм используйте размещение всего сайта на Worker по инструкции ниже.

## 1. Проверить на своём компьютере

Установите Node.js 24 LTS и pnpm 11. Откройте терминал в папке проекта:

```sh
pnpm install --frozen-lockfile
pnpm db:local
pnpm preview:local
```

Откройте `http://127.0.0.1:8787`. Сервер работает, пока открыт терминал. Заявки этого режима попадают только в локальную базу `.wrangler/state`. Без секретов Telegram уведомления не отправляются.

Проверки:

```sh
pnpm test
pnpm typecheck
pnpm lint
pnpm build
pnpm check:deploy
```

`check:deploy` — сборка Worker без публикации. `build` — отдельная проверка исходного приложения Vinext. Для бесплатного самостоятельного размещения ниже используется конфигурация `wrangler.production.json`, а не `dist/server/wrangler.json`.

Не публикуйте только папку `public` на обычном статическом хостинге: формы требуют сервер `/api/requests`.

## 2. Бесплатное размещение

По официальной документации на дату подготовки:

- [Workers Free](https://developers.cloudflare.com/workers/platform/pricing/) включает 100 000 обращений к Worker в сутки; CPU-лимит бесплатного плана — 10 мс на вызов.
- [Статические файлы](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/) обслуживаются бесплатно, без лимита количества запросов к файлам.
- [D1 Free](https://developers.cloudflare.com/d1/platform/pricing/) включает 5 млн прочитанных и 100 000 записанных строк в день, до 5 ГБ общего хранения. Запросы к БД учитываются отдельно от посетителей. При исчерпании бесплатных лимитов сервис ограничивает операции; не включайте Workers Paid для старта.
- [Telegram Bot API](https://core.telegram.org/bots/faq) позволяет обычную отправку сообщений бесплатно в пределах лимитов. Покупать Stars для этой интеграции не нужно.

Лимиты относятся к аккаунту и могут меняться. Домен `arthomey.ru`, если он нужен, оплачивается и продлевается отдельно у регистратора. Для начала можно использовать адрес вида `art-homey.ВАШ-ПОДДОМЕН.workers.dev`.

### Подключение вашего аккаунта

1. Создайте аккаунт Cloudflare и оставьте Workers на плане **Free**. В разделе Workers & Pages выберите свой поддомен workers.dev.
2. В терминале проекта выполните:

```sh
pnpm exec wrangler login
pnpm exec wrangler d1 create art-homey
```

Команда создания базы выведет `database_id`. Сохраните его. Далее подставьте свой адрес и ID:

```sh
pnpm configure:hosting https://art-homey.ВАШ-ПОДДОМЕН.workers.dev ВАШ_DATABASE_ID
```

Команда создаст `wrangler.production.json` и обновит адреса в canonical, Open Graph, sitemap и robots. Она ничего не публикует. Если используете другой Worker name, согласуйте его в конфигурации и адресе.

3. Создайте таблицы в вашей новой базе:

```sh
pnpm exec wrangler d1 migrations apply DB --remote --config wrangler.production.json
```

Для новой пустой базы применяются обе миграции. Если подключаете уже работающую базу с таблицей `requests`, сначала сделайте резервную копию и согласуйте историю миграций; повторно создавать таблицу нельзя. Существовавшие до второй миграции заявки отмечаются `legacy-manual-review` и автоматически в Telegram не рассылаются.

4. Опубликуйте сайт:

```sh
pnpm exec wrangler deploy --config wrangler.production.json
```

Команда вернёт адрес. Пока секреты Telegram не добавлены, заявки сохраняются в D1, уведомления остаются в ожидании. Подключите бота до привлечения посетителей.

## 3. Подключить Telegram

1. В Telegram откройте официальный [@BotFather](https://t.me/BotFather), выполните `/newbot`, задайте имя и получите токен.
2. Скопируйте `.dev.vars.example` в `.dev.vars` и впишите токен в `TELEGRAM_BOT_TOKEN`. Это приватный локальный файл, он исключён из Git. Не вставляйте токен в HTML, JavaScript страницы или публичный чат.
3. Напишите `/start` своему боту. Если заявки должны приходить в рабочую группу, добавьте туда бота и отправьте `/start@имя_вашего_бота`.
4. Получите ID чата:

```sh
node --env-file=.dev.vars scripts/telegram-chat-id.mjs
```

Скрипт читает список обновлений вашего бота и выводит ID найденных чатов. Он не отправляет сообщения. Впишите нужный ID в `TELEGRAM_CHAT_ID` в `.dev.vars`.

5. Добавьте оба значения как секреты опубликованного Worker. Команды предложат ввести значения скрыто:

```sh
pnpm exec wrangler secret put TELEGRAM_BOT_TOKEN --config wrangler.production.json
pnpm exec wrangler secret put TELEGRAM_CHAT_ID --config wrangler.production.json
```

6. Отправьте по одной тестовой заявке из короткой формы и квиза на опубликованном сайте. Проверьте запись в D1 и сообщение в выбранном чате. Планировщик запускается каждую минуту; новая настройка Cloudflare может примениться не мгновенно.

Уведомление содержит имя, телефон, задачу, бюджет и выбранный канал связи. Перед запуском приведите опубликованную политику обработки данных в соответствие фактическим сервисам и реквизитам компании: исходный текст политики в архиве не был юридически переработан.

Доставка устроена по принципу «как минимум один раз»: в редком случае обрыва после отправки Telegram, но до отметки в БД, уведомление может прийти повторно с тем же номером заявки. Сама запись заявки при обычном повторе формы не дублируется.

## 4. Где смотреть заявки и сбои

В Cloudflare откройте D1 → вашу базу → Console. Например:

```sql
SELECT id, category, budget, name, contact, message, created_at, notified_at
FROM requests ORDER BY created_at DESC LIMIT 50;
```

`notified_at IS NULL` означает, что подтверждённой отправки в Telegram ещё нет. `notification_attempts` показывает количество попыток, `notification_next_at` — время следующей попытки в миллисекундах Unix. На локальном сервере расписание само не запускается; тестовый вызов: `http://127.0.0.1:8787/cdn-cgi/handler/scheduled`.

Секреты и сообщения клиентов не записываются в журнал приложения. Для контроля используйте доступ к базе только через свой аккаунт Cloudflare. Публичной административной страницы в проекте нет.

## 5. Перед рекламой

Проверьте сайт на реальных телефонах, доступность из региона клиентов, получение заявок и просмотр фотографий. Автоматические проверки DOM не заменяют визуальную проверку Safari/Chrome на мобильном устройстве.

Адрес `https://arthomey.ru` оставлен из исходника как исходное значение метаданных. Команда `configure:hosting` должна быть выполнена с фактическим адресом публикации.
